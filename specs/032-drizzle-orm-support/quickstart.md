# Quickstart: Drizzle ORM with IRIS PGWire

**Feature**: 032-drizzle-orm-support
**Date**: 2025-12-25

## Prerequisites

- IRIS PGWire server running on `localhost:5432`
- Node.js 18+ installed
- npm or pnpm package manager

## Step 1: Create Drizzle Project

```bash
mkdir drizzle-iris-demo
cd drizzle-iris-demo
npm init -y
npm install drizzle-orm postgres
npm install -D drizzle-kit typescript @types/node ts-node
npx tsc --init
```

## Step 2: Configure Drizzle

Create `drizzle.config.ts`:

```typescript
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  dialect: 'postgresql',
  schema: './src/schema.ts',
  out: './drizzle',
  dbCredentials: {
    host: 'localhost',
    port: 5432,
    user: '_SYSTEM',
    password: 'SYS',
    database: 'USER',
    ssl: false,
  },
});
```

## Step 5: Create Database Client

Create `src/db.ts`:

```typescript
import { drizzle } from 'drizzle-orm/postgres-js';
import postgres from 'postgres';
import * as schema from './schema';

const connectionString = 'postgresql://_SYSTEM:SYS@localhost:5432/USER';

const client = postgres(connectionString);
export const db = drizzle(client, { schema });
```

## Step 6: Test CRUD Operations

Create `src/test-crud.ts`:

```typescript
import { db } from './db';
import { users } from './schema';
import { eq } from 'drizzle-orm';

async function testCrud() {
  console.log('🧪 Testing Drizzle ORM with IRIS PGWire\n');

  // INSERT with .returning()
  console.log('1. INSERT with .returning()');
  const inserted = await db.insert(users).values({
    name: 'Alice',
    email: 'alice@example.com',
  }).returning();
  console.log('   Inserted:', inserted);
  const userId = inserted[0].id;

  // SELECT
  console.log('\n2. SELECT');
  const selected = await db.select().from(users).where(eq(users.id, userId));
  console.log('   Selected:', selected);

  // UPDATE with .returning()
  console.log('\n3. UPDATE with .returning()');
  const updated = await db.update(users)
    .set({ name: 'Alice Smith' })
    .where(eq(users.id, userId))
    .returning();
  console.log('   Updated:', updated);

  // DELETE with .returning()
  console.log('\n4. DELETE with .returning()');
  const deleted = await db.delete(users)
    .where(eq(users.id, userId))
    .returning();
  console.log('   Deleted:', deleted);

  console.log('\n✅ All CRUD operations completed successfully!');
  process.exit(0);
}

testCrud().catch(err => {
  console.error('❌ Error:', err);
  process.exit(1);
});
```

## Step 7: Test Transactions

Create `src/test-transaction.ts`:

```typescript
import { db } from './db';
import { users } from './schema';

async function testTransaction() {
  console.log('🧪 Testing Transactions\n');

  try {
    await db.transaction(async (tx) => {
      // Insert user
      const user = await tx.insert(users).values({
        name: 'Bob',
        email: 'bob@example.com',
      }).returning();
      console.log('   Inserted in transaction:', user[0].name);

      // This would rollback on error
      // throw new Error('Simulated error');
    });

    console.log('✅ Transaction committed successfully!');
  } catch (err) {
    console.error('❌ Transaction rolled back:', err);
  }

  // Verify
  const allUsers = await db.select().from(users);
  console.log('\nAll users after transaction:', allUsers);

  process.exit(0);
}

testTransaction().catch(console.error);
```

## Troubleshooting

### Connection Refused
- Ensure IRIS PGWire is running: `docker ps | grep iris`
- Restart container: `docker restart iris-pgwire-db`

### Introspection Returns Empty Schema
- Verify tables exist in SQLUser schema
- Check schema mapping is working (public → SQLUser)

### RETURNING Not Working
- Ensure Feature 031 is deployed (RETURNING clause emulation)
- Restart container to load latest code

### Type Mismatch Errors
- Check type OID mapping in protocol.py
- Verify column types in IRIS match expected PostgreSQL types
